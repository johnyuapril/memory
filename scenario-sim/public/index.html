        ⚙ API 설정

        API 키를 넣으면 실제 시뮬레이션이 동작합니다. 키는 이 기기 안에만 저장되고 해당 회사의 API로만 전송됩니다. 비워 두면 모의 모드로 동작합니다.

        Claude

        키 발급: console.anthropic.com → API Keys (크레딧 충전 필요)

        Gemini

        키 발급: aistudio.google.com → Get API key (무료). 무료 사용량은 분당 요청 수가 적어, 한도에 걸리면 앱이 잠시 기다렸다가 다시 시도합니다. 결제를 연결한 프로젝트의 키는 무료 사용량이 적용되지 않을 수 있습니다.
