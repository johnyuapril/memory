# 시나리오 시뮬레이터

인물의 성격과 배경(시대·장소)을 자세히 설정하고 시간을 흘려보내면, Claude가 그 사이 인물들의 실제 삶을 시뮬레이션해 변화를 반영하는 시나리오 개발 도구입니다.
사용자는 그 세계의 **신**이 되어 원하는 날짜에 사건을 던져 넣고, 인물들이 어떻게 반응하는지 지켜볼 수 있습니다.

> 예) 1820년 5월 1일 런던에 사는 18세 학생 에드워드 → 목표 날짜를 1822년 7월 3일로 정하고 실행 → 2년 2개월 동안의 사건·관계 변화·성격 변화·새 인물·이야기가 쌓이고, 에드워드는 20세가 됩니다.

## 실행

```bash
cd scenario-sim
npm install
export ANTHROPIC_API_KEY=sk-ant-...   # Claude 사용 (또는 아래 Gemini)
# export GEMINI_API_KEY=AIza...       # Gemini 사용 (무료 사용량 있음)
npm start                             # http://localhost:3000  (키가 없으면 모의 모드)
```

| 환경 변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Claude API 키 |
| `GEMINI_API_KEY` | — | Gemini API 키 |
| `SIM_PROVIDER` | 키가 있는 쪽 | `anthropic` 또는 `gemini` (둘 다 있으면 Claude) |
| `SIM_MODEL` | `claude-opus-5-5` / `gemini-flash-latest` | 시뮬레이션에 쓸 모델 |
| `SIM_EFFORT` | `medium` | Claude 사고 깊이 (`low` / `medium` / `high` / `xhigh` / `max`) |
| `SIM_MOCK` | — | `1`이면 API 키가 있어도 모의 엔진 사용 (`npm run mock`) |
| `SIM_DATA_DIR` | `./data/worlds` | 세계 저장 위치 |
| `PORT` | `3000` | 서버 포트 |

## 안드로이드 앱 (테스트 버전)

서버 없이 폰 안에서 전부 동작하는 앱입니다. 세계 데이터는 기기(IndexedDB)에 저장되고, 시뮬레이션은 앱이 Anthropic API를 직접 호출합니다.

### APK 받기

1. GitHub 저장소의 **Actions → "Android 테스트 APK"** 워크플로에서 최근 성공한 실행을 엽니다. (`scenario-sim/` 변경이 푸시되면 자동 실행, 수동 실행도 가능)
2. 맨 아래 **Artifacts**의 `scenario-sim-android-test`를 내려받아 압축을 풀면 `scenario-sim-test.apk`가 있습니다.
3. 폰으로 옮겨 설치합니다. (처음이면 "출처를 알 수 없는 앱 설치"를 허용해야 합니다)
4. 앱을 처음 열면 **⚙ API 설정**이 뜹니다. AI 제공자(Claude 또는 Gemini)를 고르고 키를 넣으면 실제 시뮬레이션, 비워 두면 모의 모드입니다.

> API 키는 기기 안에만 저장되고 해당 회사의 API로만 전송됩니다. 개인 테스트용 구성이므로 키가 든 폰을 다른 사람에게 넘기지 마세요.

### 직접 빌드하기 (Android Studio / Android SDK 필요)

```bash
cd scenario-sim
npm install
npm run build:mobile          # public/ + mobile/entry.js → mobile/www/
npx cap add android           # 처음 한 번 (android/ 생성)
npx cap sync android
cd android && ./gradlew assembleDebug
# → android/app/build/outputs/apk/debug/app-debug.apk
```

`npx cap open android`로 Android Studio에서 열어 에뮬레이터나 USB로 연결한 폰에서 바로 실행할 수도 있습니다.

### 앱에서 다른 점

- 세계 JSON 내보내기는 파일 대신 **클립보드 복사**
- 데이터는 앱을 지우면 함께 지워집니다

## AI 제공자: Claude와 Gemini

| | Claude (Anthropic) | Gemini (Google) |
|---|---|---|
| 비용 | 유료 (크레딧 충전 필요) | 무료 사용량 있음 |
| 키 발급 | console.anthropic.com → API Keys | aistudio.google.com → Get API key |
| 모델 | Opus 5.5(기본) / Sonnet 5.5 / Haiku 5.5 / Fable 5.1 | `gemini-flash-latest`(기본), 설정의 "모델 목록 불러오기"로 키에서 쓸 수 있는 모델 선택 |

Gemini 무료 사용량 참고:
- 분당·하루 요청 수 제한이 있습니다. 한도(429)에 걸리면 앱이 15초, 30초, 45초 기다렸다가 다시 시도하고, 그래도 안 되면 멈춥니다(그때까지 결과는 저장됨). 긴 기간은 단위를 크게(3개월 등) 잡으면 호출 수가 줄어듭니다.
- 무료 사용량 조건과 모델 이름은 Google이 자주 바꿉니다. 정확한 한도는 AI Studio에서 확인하세요.
- 결제를 연결한 Google 프로젝트의 키는 무료 사용량이 적용되지 않을 수 있습니다.

## 기능

- **세계 설정**: 시대, 장소, 사회 구조, 세계 규칙(마법 유무 등), 분위기, *현실성*(낮을수록 극적인 우연 허용), *사건 밀도*
- **인물 설정**: 생년월일(나이 자동 계산), 직업, 위치, 외모, 빅파이브 성격 5요소, 특성, 가치관, 목표, 두려움, 비밀, 말투, 기술, 배경, 건강·재산·기분·지위
  - ✨ 한 줄 설명으로 시대에 맞는 인물을 AI가 생성
- **관계**: 인물 쌍마다 관계 종류, 호감도(-100~100), 신뢰도, 변화 이력. 관계도 그래프
- **시간 흐르게 하기**: 목표 날짜까지 하루/1주/1개월/3개월/6개월 단위(또는 자동)로 나누어 순서대로 시뮬레이션
  - 각 구간마다 사건, 인물 상태·성격 변화·기억, 관계 변화, 이야기(갈등) 시작·전개·해결, 새로 등장한 인물이 반영됨
  - 진행 상황이 실시간으로 표시되고, 중간에 멈추면 그때까지의 결과는 저장됨
  - **되돌리기**: 실행 직전 상태로 복원 (최근 10회)
- **⚡ 신의 개입**: 날짜·종류·강도·대상 인물을 정해 사건을 예약. 그 날짜에 반드시 일어나며, 결과가 기록됨. "지금 던지고 1주 진행"으로 즉시 확인
- **이야기 탭**: 인물들 사이에서 생겨난 이야기의 진행 단계와 결말
- **🎬 장면으로 보기**: 타임라인의 사건 하나를 대사가 있는 소설 장면으로
- **📖 연대기 쓰기**: 기간을 정해 그 사이 사건을 한 편의 장(章)으로 엮음
- **💬 인물과 대화**: 현재 시점의 인물에게 질문. 인물은 자기 성격·기억·시대의 지식으로만 대답
- **JSON 내보내기**

## 구조

```
server.js          HTTP 서버 (REST API + 시뮬레이션 진행 스트림 SSE)
src/api.js         REST 라우팅 — 서버와 안드로이드 앱이 같은 코드를 사용
src/config.js      API 키·모델 설정 (서버: 환경 변수, 앱: 설정 화면)
src/world.js       세계/인물/관계 데이터 모델, 시뮬레이션 결과 반영, 모델에 넘길 상태 요약
src/llm.js         프롬프트와 JSON 스키마, Claude 호출 (구간 시뮬레이션, 장면/연대기/대화/인물 생성)
src/gemini.js      Gemini 호출 (같은 프롬프트로 동작, 모델 목록 조회)
src/engine.js      목표 날짜까지 구간을 나눠 순서대로 실행, 구간마다 저장
src/mock.js        API 키 없이 흐름을 확인하는 모의 엔진
src/dates.js       1800년대 등 과거 날짜 계산, 구간 분할
src/store.js       세계 저장, 되돌리기 스냅샷 (store-fs.js: 서버 파일 / store-idb.js: 앱 IndexedDB)
src/sample.js      예시 세계 (1820 런던)
public/            브라우저 UI (빌드 과정 없음)
mobile/            안드로이드 앱용 진입점과 빌드 스크립트 (Capacitor)
```

### 시뮬레이션 방식

1. 현재 날짜 → 목표 날짜를 단위별 구간으로 나눕니다 (자동: 2주 이하 하루, 4개월 이하 1주, 3년 이하 1개월…).
2. 구간마다 세계 상태(설정, 모든 인물의 성격·목표·비밀·상태·인생 요약·최근 기억, 관계, 진행 중인 이야기, 최근 사건 25개)와 그 구간에 예약된 신의 개입을 Claude에 보냅니다.
3. Claude는 인물들이 각자의 동기대로 행동한 결과를 JSON으로 돌려주고, 이것이 세계에 반영된 뒤 다음 구간으로 넘어갑니다.
4. 긴 기간을 돌려도 맥락이 넘치지 않도록 인물별 기억은 40개까지 두고(중요도 낮은 오래된 기억부터 잊음), 큰 흐름은 매 구간 갱신되는 *인생 요약*에 남깁니다.
